# Contributing to Photobooth

Photobooth welcomes community contributions, whether they are bug fixes, new features, or documentation improvements.

Before you contribute, it is important to understand how this project is licensed and funded:

1. **AGPL-3.0 Everywhere:** This entire project is open-source under the GNU Affero General Public License v3.0 (AGPL-3.0). This license applies to all source code in this repository.
2. **The Creator Store Plugin:** To fund the ongoing development and maintenance of this tool, a pre-built `.rbxm` version of this plugin is sold on the Roblox Creator Store and itch.io. This pre-built version is also distributed under the AGPL-3.0; we simply charge a fee for the convenience of automatic updates and seamless Roblox Studio integration.
3. **What this means for your contributions:** By submitting a Pull Request, you agree that your contributed code will be licensed under the AGPL-3.0. Your code will be visible in this public repository and will be compiled into the official pre-built `.rbxm` plugin sold on the Creator Store.

Because everything remains unified under the AGPL-3.0, **no Contributor License Agreement (CLA) is required to contribute.**

## How to Contribute

### 1. Reporting Bugs & Suggesting Features
Before writing code, please check the [Issues tab](https://github.com/photobooth-rbx/photobooth-plugin/issues) to see if someone else has already reported the bug or suggested the feature. If not, feel free to open a new issue using one of the provided templates.

### 2. Submitting a Pull Request
* Open a Pull Request (PR) against the `main` branch.
* Provide a clear description of the changes you made and the problem they solve.
* Reference any relevant issue numbers (e.g., `Closes #12`).
